# SimpleCoder
SimpleCoder is a set of tools to leverage LLMs for software development. 

## Main Idea
As many people noted, LLMs keen to respond w/out reading whole project, which is known as partial context problem.
Since LLMs are stateless, we need to make sure it can understand the project before doing any changes. 

Assuming best LLMs have sufficient cognitive capacity, limited by context size, 
all we need is to make sure it reads the project prior doing any changes. 

The chosen way to achieve that is to print all we need into one file.
